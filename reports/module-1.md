### Serialization Decision

The service supports ONNX inference, and the project includes a test for serving with either supported format. ONNX is the preferred deployment format when cross-language portability and avoiding Pickle's arbitrary-code execution risk are important.

Pickle files should only be loaded from trusted sources. The project's Pickle artifact is generated by its own training pipeline.

## 3. Format Comparison

| Format | Human-readable | Cross-language | Schema-enforced | Safe from untrusted source |
|---|---|---|---|---|
| JSON | Yes | Yes | No, by itself | Yes, as data |
| Protobuf | No | Yes | Yes, with a schema | Yes, as data |
| Pickle | No | No, Python-specific | No | No |
| ONNX | No | Yes | Defined model graph and tensor interfaces | Does not have Pickle's arbitrary-code loading behavior |

**Decision:** ONNX is the preferred serving format for portability and safer model loading. The configured serving format should be verified against the actual application configuration before deployment.
